Using the slides

Fullscreen with F, move with the arrow keys, and press Esc for an overview of every slide. S opens a speaker view with notes, a timer and the next slide. The plots are live — drag a slider and the model is recomputed in the browser.

To get a PDF, run ./docs/export-pdf.sh from the repository. Each slide becomes one page, and every figure is captioned with the parameter values it is showing, so the handout still makes sense once the sliders no longer work.
